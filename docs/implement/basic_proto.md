## 🛠️ ツール基本設計案：Office XML Analyzer（仮）

### 1. 設計方針（ポリシー）
* **依存ゼロ**: 実行環境を選ばないよう標準ライブラリ（`zipfile`, `xml.etree.ElementTree`, `difflib`等）のみで完結させる。
* **非破壊の原則（Read-Only First）**: 複雑なXML依存関係を壊さないよう、基本は「解析と差分出力」に留め、ファイルの上書きは行わない。
* **オンメモリ処理**: `zipfile`を使ってZIPを展開せず、直接オンメモリでXMLを読み込んで処理を高速化する。
* **モジュール分割**: 「ZIP解凍層」「XMLパース層」「Officeロジック層（Excel/Word）」「差分比較層」を分離し、拡張性を高める。

### 2. システム構成イメージ
```text
[CLI / Main Script]
 │
 ├─ Core Engine
 │   ├─ ZipHandler (ファイルのメモリ展開)
 │   └─ XmlParser (名前空間の解決、要素抽出)
 │
 ├─ Excel Module
 │   ├─ WorksheetParser (sheet*.xmlの解析)
 │   └─ SharedStringParser (sharedStrings.xmlの解決)
 │
 ├─ Word Module
 │   ├─ DocumentParser (document.xmlの段落・Run解析)
 │   └─ RelationParser (リンクや画像の欠損チェック)
 │
 └─ Diff Engine
     └─ 要素同士の比較（difflibを用いた差分生成）
```

## 📦 標準モジュールのみで実現できる機能一覧

ここでは、標準モジュールで「どこまでやれるか」をExcel/Word別に具体化します。

### 📊 Excel版（.xlsx）の機能スコープ
Excelは「セルの値」が `sharedStrings.xml` に分離されていることが多いため、ここを紐付けるのが最初の関門ですが、一度紐付ければ強力な解析が可能です。

* **① 全文Grep検索**
  * `sharedStrings.xml` を走査し、特定の文字列が含まれるセルの場所（例: "A1"）を特定。
* **② セル・数式の差分抽出（Diff）**
  * 新旧2つのExcelファイルを比較し、「値が変更されたセル」「数式が書き換えられたセル」をリストアップ。
* **③ スタイル・属性の変更検知**
  * セルの背景色やフォント指定（スタイルID）が変わった箇所を検知（※具体的な色名への変換は困難だが、「IDが変わった＝書式が変更された」という検知は可能）。
* **④ 図表の存在チェック（欠損検知）**
  * `drawing*.xml` などのリレーションファイルを比較し、「旧ファイルにあった図形や画像ノードが、新ファイルで消えていないか」をチェック。

### 📄 Word版（.docx）の機能スコープ
Wordはパラグラフ（段落:`<w:p>`）とラン（文字列:`<w:r>`）の階層構造になっています。見た目の完全再現は捨てて、「論理的な構造」の解析に振り切ります。

* **① 段落単位のGrep検索**
  * テキストの途中でXMLタグが分断されるケース（文字装飾などで分かれる）を考慮し、段落ごとにテキストを結合してから文字列検索を実行。
* **② 文書の差分抽出（Diff）**
  * 段落ごとにハッシュ化、または `difflib.SequenceMatcher` を使い、「どこに追記されたか」「どの段落が削除されたか」をマークダウン風に出力。
* **③ 書式（太字・斜体）の部分抽出**
  * 特定の単語に対する `<w:b>` (太字) などのプロパティを抽出し、「この段落のこの部分は強調されている」というメタデータを取得。
* **④ リンク切れ・画像欠損チェック**
  * `_rels/document.xml.rels` を解析し、文書内に埋め込まれた画像ファイル（`media/image*.png`）がZIP内に実在するか整合性をテスト。

## 🚀 開発のロードマップ（段階的アプローチ）

複雑なXMLを扱うため、一気に作らずに以下のステップで進めるのが確実です。

* **フェーズ1（基盤構築）**: 特定のExcelファイルから `sharedStrings.xml` と `sheet1.xml` を読み込み、A1セルなどの値をターミナルに正しく `print` できる基盤を作る。
* **フェーズ2（差分エンジン実装）**: 2つのファイルを読み込み、テキストや数式の差分を抽出してコンソールに出力する。
* **フェーズ3（応用）**: 抽出した差分データをJSON等で出力し、他の自動化ツールやダッシュボードと連携できるようにする。
