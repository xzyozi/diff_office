# 実行・検証手順

| 項目       | 内容                                |
| :--------- | :---------------------------------- |
| 管理ID     | IMPL-OP-001                         |
| Python要件 | 3.10以上                            |
| GUI要件    | Tkinterが利用可能なデスクトップ環境 |
| 実行時依存 | Python標準ライブラリのみ            |

## 1. 起動方法

| 機能         | 起動コマンド                | 入力                         |
| :----------- | :-------------------------- | :--------------------------- |
| Excel差分GUI | `python prot/excel_diff.py` | `.xlsx` または `.xlsm` を2件 |
| Word差分GUI  | `python prot/word_diff.py`  | `.docx` または `.docm` を2件 |

各GUIで旧・新のファイルを選択して比較する。Excelは差分がある場合にHTMLを `output/` へ出力して既定ブラウザで開く。WordはGUI内でのみ結果を確認する。

## 2. 手動確認項目

| 対象  | 正常系                                               | 境界・異常系                                    |
| :---- | :--------------------------------------------------- | :---------------------------------------------- |
| Excel | 同名シートの値・数式差分、追加・削除シート、HTML出力 | 未選択、同一ファイル、共通シートなし、破損ZIP   |
| Word  | 置換・追加・削除の強調、差分ジャンプ、同期スクロール | 未選択、同一ファイル、破損ZIP、document XMLなし |

## 3. CIと自動検証

PRが `main` または `develop` を対象とする場合、CIはRuffのlint・format確認、追跡済みPythonファイルがある場合のMypy、テストファイルがある場合のPytestを実行する。

現行リポジトリには `tests/` と `test_*.py` が存在しないため、単体テストは未実装である。GUIの起動・Officeファイル比較・ブラウザ表示はCIでは検証しない。

## 4. 運用上の注意

入力Officeファイルは読み取りのみで更新しない。Excelレポートは比較結果を再現する永続履歴ではないため、保存が必要な場合は生成済みHTMLを別途管理する。
