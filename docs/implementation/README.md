# 現行実装ドキュメント

このディレクトリは、`prot/` 配下の実装を読み取り、現状を記録するための文書群である。将来構想を扱う `docs/implement/`、設計テンプレートを置く `docs/design/` とは分離する。

## 管理方針

- 文書IDの `IMPL` は製番ではなく、実装記録を識別するための分類コードである。
- `BD`、`DD`、`DS`、`OP` は文書種別、3桁の連番は同種文書内の識別子とする。
- 実装変更時は、影響する文書の `updated_at` と改訂履歴を同一PRで更新する。
- 実装に存在しない機能は仕様として補完せず、「未実装」または「対象外」と記録する。
